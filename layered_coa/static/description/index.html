Multi-Level Chart of Accounts Hierarchy

Layered parent-child CoA with configurable depth — Odoo 18 Enterprise

Key Features

  • Configurable depth levels — set max hierarchy depth per company
  • Parent-child account relationships — same-type accounts only
  • Leaf-only transaction posting — parent accounts auto-restricted
  • Auto-deprecation — parent accounts deprecated on child assignment
  • Hierarchy columns in Chart of Accounts list view
  • Reclassification wizard — move balances before hierarchy changes
  • Full audit trail — all changes logged via Odoo Discuss
  • Grouped financial reports — P&L, Balance Sheet, and more

Navigation

  • Settings: Accounting > Configuration > Settings > Limit Layered COA
  • Chart of Accounts: Accounting > Configuration > Chart of Accounts
  • Reclassify: Open any account form → Reclassify Transactions button
